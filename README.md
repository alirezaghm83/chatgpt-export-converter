# ChatGPT Offline Archive — بدون نصب و بدون اینترنت

**فارسی / English**: A dependency-free, local-only viewer and search tool for ChatGPT conversation exports. **One HTML file**, no Python, npm, SQLite, CDN, server or login.

## استفاده در ۳ مرحله

1. از **ChatGPT → Settings → Data Controls → Export Data** درخواست خروجی بده و ZIP دریافتی را نگه دار.
2. فایل `conversations.json` را از داخل ZIP استخراج کن.
3. فایل `index.html` را در Chrome، Edge یا Firefox باز کن و `conversations.json` را با دکمه **انتخاب فایل JSON** انتخاب کن (یا روی پنجره بکش و رها کن). تمام مراحل بدون اتصال اینترنت انجام می‌شود.

**Offline test:** اینترنت را قطع کن، `index.html` را با `file://` باز کن، و فایل JSON را انتخاب کن. هیچ سروری لازم نیست.

## قابلیت‌ها

- جست‌وجو در عنوان و متن پیام‌ها، شامل فارسی و انگلیسی؛ نرمال‌سازی حروف `ی/ي` و `ک/ك`.
- مرتب‌سازی، فیلتر تاریخ، نمایش پیام‌ها و قطعه‌های کد.
- دریافت Markdown از مکالمه انتخاب‌شده.
- انتخاب چند فایل `conversations.json` از Exportهای مختلف و ادغام بر اساس شناسه مکالمه (نسخه جدیدتر/کامل‌تر ترجیح داده می‌شود).
- **ذخیره آرشیو ادغام‌شده** به‌صورت JSON، و بارگذاری دوباره همان فایل در دفعات بعد.
- پردازش تمام داده‌ها **در مرورگر خودتان**؛ بدون آپلود، تحلیل ابری یا درخواست شبکه.

## حریم خصوصی

- فقط فایل‌های سورس این ابزار را در GitHub منتشر کنید؛ **هرگز** `conversations.json`، فایل ZIP خروجی، عکس، کلید، توکن یا آرشیو خصوصی‌تان را در ریپوی عمومی Commit نکنید.
- این ابزار فایل JSON را در حافظه تب نگه می‌دارد و بعد از Refresh یا بستن تب آن را از دست می‌دهد، مگر اینکه آرشیو ادغام‌شده را خودتان ذخیره کنید.
- فایل خروجی ادغام‌شده **رمزنگاری نشده** است. آن را مانند دیگر اطلاعات حساس روی دیسک امن نگهداری کنید؛ برای کپی VPS از ابزار رمزنگاری سمت کاربر استفاده کنید.
- سیاست امنیت محتوا (CSP) تمام اتصال‌های شبکه (`connect-src`) را مسدود می‌کند و هیچ منبع خارجی بارگذاری نمی‌شود.

## محدودیت‌ها

- این ابزار **متن گفتگوها** را نگه می‌دارد و شاخه جاری (`current_node`) هر مکالمه را نمایش می‌دهد. شاخه‌های دیگر پاسخ‌های بازتولیدشده، تصویرها، فایل‌های ضمیمه و برخی داده‌های چندرسانه‌ای ممکن است در JSON ادغام‌شده وجود نداشته باشند. **ZIP اصلی را همیشه جداگانه نگه دارید**.
- ساختار خروجی ChatGPT ممکن است در آینده تغییر کند. اگر ساختار فایل ناشناخته باشد، برنامه خطا نشان می‌دهد.
- روی خروجی‌های بسیار بزرگ، RAM مرورگر و زمان بارگذاری محدودیت ایجاد می‌کنند؛ اگر لازم شد چند خروجی کوچک‌تر استفاده کنید.
- جست‌وجو ساده و متنی است و Semantic Search یا Markdown Renderer کامل ندارد. رنگ‌آمیزی جست‌وجو در پیام‌ها محدود است.
- ابزار اصلی برای استفاده محلی و آفلاین طراحی شده و باز کردن آن روی هاست عمومی همراه با داده‌های شخصی توصیه نمی‌شود.

## برای توسعه‌دهندگان

هیچ مرحله Build وجود ندارد. فایل `index.html` هم سورس برنامه است و هم فایل اجرایی. برای آزمایش ابتدایی از `tests/sample-conversations.json` استفاده کنید.
